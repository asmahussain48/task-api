# Task API

A simple CRUD API built with Python and FastAPI. It manages tasks using an in-memory list and supports creating, reading, updating, and deleting tasks.

## Features

- Create a task
- List all tasks
- Get one task
- Update a task
- Delete a task
- Input validation
- JSON error responses
- Swagger UI documentation
